# Module 01 — Python Foundations

**Course:** Python 0–100, Edition 2  
**Environment:** macOS, Python 3, terminal  
**Capstone direction:** Mother — a small environment-aware machine-learning application

## Purpose

This module establishes the mental models required to read, write, and reason about Python. It begins with how the interpreter executes instructions, then covers types and expressions, and finally introduces data structures for representing environmental observations.

## Learning objectives

By the end of the module you should be able to:

1. Explain object references, rebinding, and mutation.
2. Use fundamental Python types, operators, and Boolean expressions.
3. Read and manipulate strings, lists, and dictionaries.
4. Choose structures that represent the relationships between pieces of data.
5. Implement small programs from written requirements without adding unnecessary complexity.

## Workflow

1. Read the lesson textbook.
2. Read its exercise specification and predict results *before* running code.
3. Create the corresponding `.py` file yourself, beginning empty. The specifications may provide starting data, but no solutions.
4. Submit the program and written answers for review; correct any issues before advancing.
5. Complete `assessment.md` once all three lessons are reviewed.

## File conventions

- Textbook and exercise instructions are raw, portable Markdown.
- Exercises are separate from the textbook and implementation.
- Your `.py` solutions are yours to write; we do not scaffold solved programs.
- `lesson01.py` in the included folder is preserved exactly as supplied, containing only its original comment.
- The module assessment is not a substitute for the individual lessons.

## Assessment

`assessment.md` contains a 10-question knowledge test, three programming challenges, and two design questions. It does **not** contain an answer key.
