# Module 02 — Control Flow and Functions

**Course:** Python 0–100, Edition 2  
**Module:** 02 of 10  
**Prerequisites:** Module 01 — Python Foundations  
**Environment:** macOS, Python 3; no third-party packages required

## Purpose

Module 01 established how Python represents and evaluates data. Module 02 is about **doing work with that data** and arranging that work into reusable responsibilities. These lessons are based on our previous Lessons 4–6, rewritten as permanent textbook chapters.

## Learning outcomes

After this module, you should be able to:

1. Process ordered observations with `for` loops and accumulate results.
2. Use `while` safely and explain termination conditions.
3. Distinguish independent `if` statements from an exclusive `if`/`elif`/`else` chain.
4. Avoid stale Boolean state when processing successive observations.
5. Design functions with explicit parameters and useful return values.
6. Separate computation and classification from presentation.
