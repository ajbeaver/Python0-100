**Course:** Python 0–100, Edition 2

## Purpose

Define a deterministic pipeline with replaceable input and persistence boundaries. Each chapter introduces a model, makes its behavior observable, and asks you to build independently from written requirements.

## Workflow

1. Read the chapter and predict example behavior before running it.
2. Create your own empty source files beside each exercise specification.
3. Save predictions, commands, output, and reasoning in its separate answers file.
4. Reproduce the evidence and review cases you cannot yet explain.
5. Complete the [100-point assessment](assessment.md) after all three exercises.

## Mother checkpoint

Define a deterministic pipeline with replaceable input and persistence boundaries.

Keep CPU units as percentages in [0, 100]. The basic fixed rule is strictly greater than the configured threshold; equality is normal. The learned residual rule introduced in Module 09 is a separate decision. Use supplied local data throughout the required course.

## Completion

The assessment allocates 30 points to knowledge, 50 to independent implementation, and 20 to design reasoning. No starter implementations or completed solutions are supplied. See [setup](../setup.md) for environment and submission conventions.
